# 006 - Destruindo Ambiente

Este notebook remove objetos criados pelo projeto.

## Uso

Ele deve ser executado somente quando for necessario limpar o ambiente, por exemplo:

- reiniciar o trabalho do zero;
- remover tabelas de teste;
- apagar schemas criados durante o desenvolvimento.

## Atencao

Este notebook nao faz parte da Job principal do pipeline.

Executar esse notebook pode apagar tabelas, volumes ou schemas usados pelos demais notebooks. Por isso, ele deve ser usado com cuidado e apenas quando a limpeza for intencional.

## Papel no Projeto

O notebook de destruicao ajuda no ciclo de desenvolvimento, permitindo recriar o ambiente de forma limpa antes de uma nova execucao completa.
